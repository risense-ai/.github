## `01` 我们做什么

Respire（`rsrs`）是一层属于用户自己的长期记忆。它不把上下文锁进某一家模型或某一个编辑器，而是让记忆在本地生长、在设备之间流动、在不同 Agent 之间延续。

<table>
  <tr>
    <td width="50%" valign="top">
      <strong>🧠 每轮自动召回</strong><br />
      <sub>按标题档检索，把真正相关的上下文带回对话，而不是把全部历史塞进窗口。</sub>
    </td>
    <td width="50%" valign="top">
      <strong>💾 本地优先，按需同步</strong><br />
      <sub>记忆先落本地，再按需加密同步。离线可用，账号只是可选项。</sub>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <strong>🔌 多端即插即用</strong><br />
      <sub>CLI、桌面端，以及 Codex、Qoder、Kimi、WorkBuddy、Dim、ZCode 等编辑器与 Agent。</sub>
    </td>
    <td width="50%" valign="top">
      <strong>🔄 开放且可迁移</strong><br />
      <sub>记忆属于用户：可导出、可合并、可演进，也可以随时带走。</sub>
    </td>
  </tr>
</table>

## `02` 核心项目

### [respire-cli](https://github.com/risense-ai/respire-cli)

`Rust` · `CLI` · `Local-first`

Respire 的命令行与本地记忆引擎。记忆的写入、召回、同步与维护，都从这里开始。

![stars](https://img.shields.io/github/stars/risense-ai/respire-cli?style=flat-square&color=0f766e&label=stars)
![forks](https://img.shields.io/github/forks/risense-ai/respire-cli?style=flat-square&color=0f766e&label=forks)

### [respire-server](https://github.com/risense-ai/respire-server)

`Rust` · `Sync` · `Encrypted`

加密同步与账号服务，让多台设备共享同一份记忆，同时不把明文交出去。

![stars](https://img.shields.io/github/stars/risense-ai/respire-server?style=flat-square&color=0f766e&label=stars)
![forks](https://img.shields.io/github/forks/risense-ai/respire-server?style=flat-square&color=0f766e&label=forks)

### [respire-client](https://github.com/risense-ai/respire-client)

`JavaScript` · `Desktop` · `Web UI`

桌面客户端与本地 Web 界面，把记忆变成可以浏览、检索和整理的东西。

![stars](https://img.shields.io/github/stars/risense-ai/respire-client?style=flat-square&color=0f766e&label=stars)
![forks](https://img.shields.io/github/forks/risense-ai/respire-client?style=flat-square&color=0f766e&label=forks)
